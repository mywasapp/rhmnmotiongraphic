# RHMN Motion Graphic Studio

Repository resmi proyek RHMN Motion Graphic Studio.

## Batch 02 — RACHMANZO Motion Assets
Di folder `stock-batch-02/` tersedia *source* visual Canvas yang dirancang untuk memproduksi 12 konsep motion graphics prosedural pada resolusi 4K UHD 3840×2160. Seluruh aset berupa ilustrasi original berbasis kode, tidak menggunakan logo, musik, gambar pihak ketiga, atau materi generatif gambar/video AI.

Workflow rendering otomatis: `.github/workflows/stock-batch-02.yml`. Hasil video adalah artefak GitHub Actions jika dan hanya jika workflow berhasil.

**Perhatian:** status unggahan dan lisensi Adobe Stock/Shutterstock belum diverifikasi; lakukan peninjauan visual dan hak atas konten sebelum publikasi.
